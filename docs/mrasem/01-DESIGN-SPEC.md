# 01 — مواصفات الديزاين (Design Spec)

كل القيم هنا منقولة من مصدر الديزاين (CSS + JS). التحويل: `1px = 1dp` للمسافات، و`1px = 1sp` للخطوط.

## 1. الهوية

- عنّابي قطري فوق محايدات رملية/لؤلؤية؛ **الذهبي للحالة والتمييز فقط** (الخطوة الحالية، التنبيهات، الوقت الحر).
- عرض الموبايل فقط، RTL، هيدر ثابت + محتوى scroll واحد + Bottom bar ثابت.

- ألوان شعارات الخدمات ثابتة من البيانات (حقل `c`).

## 7. شاشات الضيف

### 7.1 المهمة (mission)
1. **Notices** (آخر تنبيهين للوضع الحالي، الأحدث أولاً) — لو موجودة.
2. **Hero**: pill (`country`) + label الجهة المستضيفة (`host`) ← الوجهة (`dest`) ← الضيف (`guest`) ← 3 stats:
   - أيام على الوصول (`start − اليوم`؛ لو ≤ 0 يظهر «اليوم / موعد الوصول»)
   - أيام المهمة (`end − start + 1`)
   - عدد الفقرات الرسمية (كل العناصر غير الوقت الحر)
   
   ثم kv: التوقيت، العملة، الطقس.
3. **حالة الوصول**: 4 خطوات + زر primary block:
   - الخطوات: «هبوط الطائرة وتأكيد الوصول» ← «{المستقبِل} بانتظارك – {نقطة اللقاء}» ← «السائق {الاسم} في طريقه إلى نقطة الالتقاء» ← «التوجه إلى الفندق»
   - نص الزر: 0 ← «وصلت: أبلغ المستقبِل والسائق»، 1–3 ← «الخطوة التالية»، 4 ← «تم الوصول إلى الفندق» (disabled) + pill ok «اكتمل» في العنوان.
   - Toast لكل ضغطة (بالترتيب): «**تم إبلاغ المستقبِل والسائق.** {الاسم} بانتظارك.» / «**السائق في الطريق** إلى نقطة الالتقاء.» / «**أهلاً بك.** جارٍ التوجه إلى الفندق.» / «**وصلت إلى الفندق.** نتمنى لك إقامة طيبة.»
4. **من سيستقبلك** (+ pill «محدَّث» لو اتعدّل): أفاتار + الاسم + المسمى، kv (الهاتف LTR، نقطة اللقاء)، زرّين: «اتصال» (`tel:`) و«واتساب» (`https://wa.me/{digits}`).
5. **السيارة الرسمية** (+ «محدَّث»): النوع + «السائق: …» + اللوحة.
6. **موقع الملتقى** (+ «محدَّث»): اسم المبنى، الخريطة، kv (المنطقة، المدخل، الطابق، القاعة، المواقف)، زر «فتح في الخرائط» (`https://www.google.com/maps/search/?api=1&query={lat},{lng}`).
7. **الإقامة**: kv (الفندق – المنطقة، الغرفة، الإفطار، المسافة).
8. **بطاقة المرور الرقمية**: QR + اسم الضيف + «تُبرز عند مدخل {المبنى}».
9. **الطوارئ**: kv لجهات الطوارئ (القيمة LTR) + «منسق المراسم المكلّف: {الاسم}، متاح على مدار الساعة.»

### 7.2 البرنامج (plan)
- Notices ← DayTabs ← كارت «البرنامج اليومي» (+ label التوقيت).
- فقرة عادية: الوقت + العنوان (+ pill «تغيّر الموعد» وخلفية ذهبية لو متغيرة) + المكان + ملاحظة اختيارية. الفقرة `key` عليها chip «بطاقة الـ ٣٠ ثانية قبل اللقاء» ← يفتح تاب البروتوكول.
- وقت حر: «وقت حر حتى {to}» + «{hours} ساعات متاحة. اقتراحات قريبة من موقعك:» + لحد 3 chips بأماكن تحقق `dur + min/30 ≤ hours` ← الضغط يفتح «استكشف» بفلتر «الكل».
- اليوم الافتراضي: inbound = اليوم الثاني، outbound = اليوم الأول.

### 7.3 الخدمات (services)
- كارت لكل فئة (التوصيل، سيارات الأجرة، النقل العام) فيه `ServiceRow` لكل خدمة؛ «فتح» يفتح الرابط خارجياً.
- كارت «معلومات سريعة» (kv) + «التوصيل إلى الفندق: رقم الغرفة {room} محفوظ مسبقاً لتسهيل الطلب.»

### 7.4 استكشف (explore)
- كارت «حول {الفندق}» + «مرتبة حسب زمن الوصول بالسيارة من الفندق. اختر الوقت المتاح لديك:» + chips: الكل / ساعة (`dur ≤ 1`) / ساعتان (`≤ 2`) / نصف يوم (`≤ 4`) / يوم كامل (الكل).
- القائمة مرتبة تصاعدياً بـ `min`. كل `PlaceCard`: الاسم + tag، الوصف، meta («{min} دقيقة بالسيارة» · «مدة الزيارة نحو {dur} ساعة/ساعات» (ساعات لو > 2) · «مناسب لكبار الضيوف»)، زر:
  - «أرغب في الزيارة» (primary) ← ينشئ طلب + Toast «**أُرسل طلبك** إلى منسق المراسم لترتيب السيارة والحجز.»
  - بعد الطلب: disabled «أُرسل الطلب لمنسق المراسم»، وبعد إنجازه من الفريق: «تم الترتيب».
- تذييل: «الأزمنة تقريبية وتتغير حسب الازدحام.»

### 7.5 البروتوكول (protocol)
1. **Hero «بطاقة الـ ٣٠ ثانية»** + label «اللقاء القادم»: اسم الشخصية + kv (صيغة المخاطبة، الجلوس، الهدية، اللغة).
2. **زي اليوم** + pill ok «معتمد من فريق المراسم»: الرسمة + اسم الزي + «يصل تنبيه لكل أعضاء الوفد عند تغييره.» + عمودين (للرجال / للنساء).
3. **قبل الخروج من الفندق**: 5 checkboxes + «{n} من ٥ جاهزة» (الحالة محفوظة لكل وضع).
4. **آداب وأعراف في قطر** (inbound) / **أعراف بلد الوجهة** (outbound).
5. **الدليل الإرشادي**: 8 chips ← Toast «**دليل {الاسم}** يُفتح هنا في النسخة الكاملة من التطبيق.»

### 7.6 المساعد (assistant)
- كارت «المساعد» + label «نموذج توضيحي»: المحادثة، 6 أسئلة جاهزة chips، حقل «اكتب سؤالك…» + «إرسال».
- رسالة الترحيب: «أهلاً بك. أنا مساعد مراسم، أجيب عن أسئلة برنامجك والبروتوكول والخدمات في {المدينة}. ما لا أعرفه أحوّله إلى منسق المراسم.»
- الرد بقواعد كلمات مفتاحية (بالترتيب، أول تطابق):

| الكلمات | الرد |
|---|---|
| لبس، ألبس، زي، بشت، بدلة | زي اليوم المعتمد + «التفاصيل في قسم البروتوكول.» |
| موعد، اجتماع، لقاء، برنامج | «أقرب فقرة رئيسية: {العنوان}، {اليوم} الساعة {الوقت}، في {المكان}.» (الفقرة الرسمية رقم 5 في الترتيب العام) |
| سيار، سائق | نوع السيارة + اللوحة + السائق |
| فندق، غرفة | الفندق + المنطقة + الغرفة + المسافة |
| طعام، أكل، توصيل، جوع | أسماء تطبيقات التوصيل + «رقم غرفتك محفوظ لتسهيل الطلب.» |
| تاكسي، أجرة، مواصلات | أسماء سيارات الأجرة + «وسيارتك الرسمية متاحة للبرنامج الرسمي.» |
| سياح، أماكن، زيارة، قريب | أقرب 3 أماكن + «اطلب الزيارة من قسم استكشف.» |
| طوارئ، إسعاف، مستشفى | رقم الطوارئ + اسم ورقم المنسق |
| غير ذلك | ينشئ طلب نوعه «سؤال» + «لم أجد إجابة مؤكدة. أرسلت سؤالك إلى منسق المراسم وسيردّ عليك قريباً.» |

- تغيير الوضع يمسح المحادثة.

## 8. شاشات فريق المراسم

رأس مشترك: 3 KPIs (مراحل الوصول `n/٤` أو ✓ · طلبات جديدة · تحديثات مرسلة) + chips الأقسام (بيانات الزيارة / التغييرات / الطلبات / الأرشيف) — متزامنة مع الـ bottom bar.

| التاب | المحتوى | التفاعل |
|---|---|---|
| **الزيارة** | نموذج عنوانه اسم الضيف + «التعديل هنا يظهر فوراً في تطبيق الضيف مع تنبيه.» — 8 حقول في عمودين: اسم المستقبِل، هاتفه (LTR)، نوع السيارة، رقم اللوحة (LTR)، السائق، القاعة، الطابق، زي اليوم (بدلة رسمية / الزي الوطني مع البشت) + «حفظ وإشعار الضيف» | يعلّم الأقسام المتغيرة «محدَّث» عند الضيف، يضيف Notice، Toast «**تم الحفظ.** وصل تنبيه للضيف. انتقل إلى عرض الضيف لرؤيته.»؛ بدون تغيير: «لا توجد تغييرات لحفظها.» الحقل الفاضي يحتفظ بالقيمة القديمة |
| **التغييرات** | «رادار التغييرات»: الفقرة الرئيسية (`key`) لليوم الثاني + «تأجيل ٣٠ دقيقة»؛ ثم «إرسال تنبيه عام للوفد» (حقل + إرسال) | التأجيل: +30 دقيقة، يعلّم الفقرة changed، Notice «تأجّل موعد "{العنوان}" إلى {الوقت}. تم إبلاغ السائق والفندق.»، Toast «**تم التأجيل.** أُبلغ الضيف والسائق والفندق.»؛ التنبيه العام: Notice + Toast «**أُرسل التنبيه** لجميع أعضاء الوفد.» |
| **الطلبات** | قائمة طلبات الضيف («طلب زيارة: {المكان}» أو «سؤال: {النص}») بحالة «بانتظار الرد / تم الترتيب» | «تم الترتيب» ← الحالة done + Notice «تم ترتيب طلبك: {المكان}» (أو «تم الرد على سؤالك») + Toast «**تم.** وصل إشعار للضيف.»؛ حالة فاضية بنصها من المصدر |
| **الأرشيف** | kv: الضيف، الجهة، الفترة، الفقرات، سجل الهدايا + وصف التقرير + زر «إنشاء تقرير الزيارة» | Toast «**تقرير الزيارة** يُنشأ تلقائياً ويُحفظ في الأرشيف في النسخة الكاملة.» |

نصوص Notice عند الحفظ:
- لو الزي اتغيّر: «تم اعتماد زي اليوم: {الزي}، وتحديث بيانات الزيارة.»
- غير كده: «تم تحديث بيانات الاستقبال أو السيارة أو القاعة. راجع بطاقة المهمة.»
